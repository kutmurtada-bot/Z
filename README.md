# سنابل — نظام إدارة وتوزيع الطحين

مشروع تطبيق Android عربي باتجاه RTL لإدارة العوائل وحصص توزيع الطحين وسجلات التسليم والنسخ الاحتياطي.

## قواعد العمل الثابتة
- حصة الفرد: 9 كغم.
- أجرة الفرد: 250 دينار عراقي.
- وزن الكيس: 50 كغم.
