# سنابل — نظام إدارة وتوزيع الطحين

**Flour Distribution Manager** هو تطبيق Android عربي بواجهة RTL لإدارة بيانات العوائل وحصص الطحين وسجلات التسليم والتقارير والنسخ الاحتياطي.

## قواعد التوزيع الثابتة
- حصة الفرد: **9 كغم**.
- أجرة الفرد: **250 دينار عراقي**.
- وزن الكيس: **50 كغم**.
- مثال: عائلة من 4 أفراد = **36 كغم** و **1,000 د.ع**.

## الوظائف
- إضافة العوائل وتعديلها والبحث عنها.
- تحديد المستفيد داخل صفحة التوزيع وعرض الحصة والمبلغ المستحق.
- تسجيل التسليم ومتابعة المستلمين وغير المستلمين.
- إحصائيات شهرية وتقارير.
- نسخ احتياطي واستعادة بيانات العوائل والنسخة الكاملة بصيغة JSON.
- واجهة عربية RTL ملائمة للهاتف.
- مراقبة أخطاء Sentry مع تعطيل جمع البيانات الشخصية افتراضياً وتنقية تفاصيل الطلبات.

## التطوير والاختبارات
يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run test:syntax
npm test
npx playwright install chromium
npm run test:e2e
```

## بناء Android APK
يعمل GitHub Actions على بناء نسخة Debug APK عند الدفع إلى الفرع الرئيسي أو التشغيل اليدوي. نجاح الاختبارات الآلية لا يغني عن تجربة التطبيق على هاتف Android فعلي.

## الخصوصية والبيانات
بيانات العوائل تُخزّن محلياً على الجهاز داخل التطبيق. استخدم النسخ الاحتياطي بانتظام، ولا تضع أسماء المستفيدين أو أرقام هواتفهم أو بيانات العوائل في سجلات الأخطاء.
